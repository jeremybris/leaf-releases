# Leaf Book Library: downloads

This page holds the installers of **Leaf Book Library**, a Windows desktop library for EPUB, KEPUB, MOBI, AZW3, AZW, FB2, PDF, comic archives (CBZ, CBR, 7Z) and image books. It scans the folders you choose and leaves your files where they are.

## Download

Get **Leaf Book Library Setup X.Y.Z.exe** from the [latest release](../../releases/latest) (GitHub shows the spaces of the file name as dots) and run it. Then start **Leaf Book Library** from the Start menu or the desktop shortcut and choose the folder that holds your books.

The installer is not signed yet, so Windows SmartScreen may ask you to confirm ("More info", then "Run anyway").

## Updates

Leaf looks at this page for new versions: Settings > Application > Updates > **Search for an update**. When the latest release here is newer than the version you have, Leaf asks "Do you want to download version X?"; Yes downloads the installer, checks its size and SHA-256 against what GitHub lists for it, runs it quietly and opens Leaf again when it is done; No leaves things as they are.

## What it does

- Reads books in several layouts (one page, two pages, manga right to left, scrolling documents), with a table of contents, search, text export and page summaries.
- Pen markings and highlights on PDFs, saved as a marked up copy beside the original.
- Looks up book details (author, summary, genres, ratings, covers) in online catalogues when you press **Search for Metadata**; nothing is looked up while scanning.
- Shares a library with other computers on your network (host and client, with a PIN); reading progress, layouts, marked up copies and book details are kept alike between them, one set for each profile.
- Profiles, collections, folder tabs, duplicate finder, favorites, read and unread marks.
- Reads pages aloud with voices that stay on your computer.
